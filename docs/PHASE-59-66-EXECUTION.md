## Verification boundaries
Source CI and independent hosted CI have distinct meanings. Source CI proves tested source behavior; hosted CI must compare the actual pinned revision and public static bytes. The review packet identifies source files, not a production artifact signature. Local recovery does not establish D1 Time Travel recovery. Browser emulation does not establish physical-device or WCAG conformance.

## Commercial implementation sequencing
The next post-approval increment is public informational pages and search discovery, not ad insertion. Define a separate approved production origin, publish verified scope statements and privacy controls, validate content and indexation, then explicitly approve monetization. Professional APIs require a separate data protection and security review; do not expose or monetize the sample preview endpoint.
